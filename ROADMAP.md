# Roadmap

Near-term priorities:

- Review Simplified Chinese and Korean translations and reduce fallback strings.
- Strengthen compatibility tests for provider model and API changes.
- Split large application state modules into smaller, testable units.
- Improve signed and notarized release workflows and document update delivery.
- Continue mobile-boundary work for credential storage, file I/O, and responsive layout.

Items here are directions, not commitments or delivery dates. Open an issue before starting a large change so design boundaries can be discussed first.
