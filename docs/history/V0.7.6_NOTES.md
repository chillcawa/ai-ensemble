# AI Ensemble v0.7.6 — Conversation Sidebar + Context Sets

## Conversation UX
- 送信成立後に入力欄をクリア。
- Conversationポップオーバーを廃止し、左サイドバーへ移動。
- サイドバーは開閉可能、状態をローカル保存。
- Conversationは `updated_at DESC` の最新更新順。
- 新規作成 / 切替 / 名前変更 / 削除をサイドバーから操作。

## Session Context boundary
- `ContextItem` に `conversationId` を追加。
- Session Contextは作成元Conversationだけに適用。
- 新規未保存Conversationではdraft session IDを使い、最初の送信時に実Conversation IDへ移行。
- Conversationを切り替えても、別ConversationのSession Contextは送信されない。

## Context Set
Context Set = 複数ContextItemを束ねる再利用可能なプリセット。

- 作成 / 名前変更 / 複製 / 削除
- ContextItemのSetへの追加/除外
- Conversationごとに選択Setを保存
- Setごとの推定token数表示
- Global InstructionはSetの外で常時適用
- Session ContextはSetの外でConversation単位
- Set選択時は、非Global・非SessionのContextだけをSet membershipで絞り込む
- Set未選択は従来互換の「手動（有効項目をそのまま使用）」

## Design invariants retained
1. Instruction != Reference
2. Import != Context
3. Context追加 != 永続保存
4. 永続保存 != 即時送信
5. AI Response != System Prompt
6. AI -> AI = 人間承認1ホップ
7. Context超過でも自動削除/自動要約しない
