# AI Ensemble v1.0.0

- Promoted the application from Preview to the first stable version.
- Added a distribution-safe build command: `npm run tauri:build`.
- NSIS is now the default and configured Windows bundle target.
- The release build remaps the project, Cargo, and user-home source paths to
  generic paths before compiling Rust.
- Release debug information is disabled and symbols are stripped.
- After a Windows build, the command inspects the application executable and
  fails if it finds the build user's home/name, known API-key patterns, or a
  non-GUI PE subsystem.
- The unmodified Tauri build remains available as `npm run tauri:build:raw` for
  development and diagnosis.
- UI and documentation labels were updated from Preview to v1.0.0.
- Existing installations show the renamed v1.0 usage notice once after upgrade.
- Fixed the Turn comparison modal so its background, text, borders, inputs,
  markers, and search highlights remain readable in both light and dark themes.

## Windows release gate

Before distribution, verify on Windows:

1. `npm run typecheck`
2. `npm run build`
3. `npm run tauri:build`
4. New installation and launch
5. Export current user data, create a temporary change, restore the export, and
   confirm that the earlier state returns while Credential Store API keys remain
   unchanged
