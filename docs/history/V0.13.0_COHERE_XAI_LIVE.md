# AI Ensemble v0.13.0 — Cohere and xAI live adapters

AI Ensemble now exposes nine optional AI slots. A slot without a saved API key
is never included in a broadcast.

## Cohere

- OS Credential Store key handling.
- Official OpenAI Compatibility API chat and SSE streaming.
- Native `GET /v1/models?page_size=1000&endpoint=chat` discovery.
- Deprecated and non-chat models are filtered from the picker.
- Curated startup choices:
  - `command-a-plus-05-2026`
  - `command-a-reasoning-08-2025`
- Evaluation/Production key type is not inferred from API responses; the app
  records tokens without inventing a billed cost.

## xAI / Grok

- OS Credential Store key handling.
- Official xAI Chat Completions API chat and SSE streaming.
- Official `GET /v1/models` discovery.
- Imagine, video, voice, embedding, multi-agent and Build models are excluded
  from this plain-chat adapter.
- Curated startup choices:
  - `grok-4.20-0309-non-reasoning`
  - `grok-4.5`
- A key may be created without active credit, but inference normally requires
  prepaid credit or an invoiced billing agreement. Billing is never enabled by
  AI Ensemble.

## Validation order

1. Windows: `npm run typecheck`, `npm run build`, `npm run tauri:dev`.
2. Cohere: save an Evaluation Key, refresh models, send a short prompt.
3. Grok: save a key, refresh models. If the team has credit, send a short
   prompt; otherwise confirm the localized billing/permission error.
4. Send once with every configured slot and confirm that one provider failure
   does not interrupt the other AI responses.
