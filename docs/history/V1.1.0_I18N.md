# AI Ensemble v1.1.0 — Japanese / English UI

## 実装内容

- 日本語・英語のUI切り替え
- OS言語の自動判定（日本語以外は英語へフォールバック）
- 設定画面からの手動固定
- 選択言語のローカル保存
- バックアップJSONへの言語設定の追加と復元
- v1.0系バックアップ（言語項目なし）との復元互換

## 翻訳範囲

質問送信、回答表示、Conversation Log、Context、Handoff、比較、Text Pad、設定、Usage、
初回注意画面など、日常操作の主要UIを対象としています。

利用者が入力した本文、AI回答、Context本文、Project名、Conversation名、モデル名は翻訳しません。
外部AI事業者から返るエラーは、診断情報を保つため原文が残る場合があります。
