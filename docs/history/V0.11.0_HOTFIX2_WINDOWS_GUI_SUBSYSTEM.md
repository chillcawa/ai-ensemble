# v0.11.0 hotfix2 — Windows GUI subsystem

## Fix

ReleaseビルドのWindows実行ファイルをConsole subsystemではなくGUI subsystemとして生成する。

`src-tauri/src/main.rs`へTauri標準属性を追加:

```rust
#![cfg_attr(not(debug_assertions), windows_subsystem = "windows")]
```

- Debug build: consoleを維持
- Release / installer build: 黒いconsole windowを表示しない

## Windows verification

```powershell
npm run typecheck
npm run build
npm run tauri:build
```

生成されたNSIS Setup.exeをインストールし、AI Ensemble起動時に黒いconsole windowが出ないことを確認する。
