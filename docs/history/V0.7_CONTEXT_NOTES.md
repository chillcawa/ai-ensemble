# AI Ensemble v0.7 Context / One-hop Cross Reference

## Implemented
- Context UI with Global / workspace Project / per-slot AI-specific instructions.
- Reference Context list with enable/disable, session/persistent toggle, delete, provenance display.
- Persistent Context stored locally; session Context is not persisted.
- Context token estimate and known model context-limit warning. No automatic deletion or summarization.
- TextPad -> Context reference.
- Completed AI response -> session Context reference, retaining provider/model and generation metadata.
- Per-slot Context assembly on send. Instructions and references remain separated internally.
- Context-aware pre-send cost estimate.
- Human-approved one-hop AI response handoff: critique / verify / improve / summarize / free-form.
- Handoff source answer is injected as an ephemeral Reference, never a System instruction and never automatically persisted.
- Handoff results are shown separately so original comparison results remain intact.

## Context invariants
1. Instruction != Reference
2. Import != Context
3. Add to Context != Persist
4. Persist Context != Send immediately
5. AI Response != System Prompt
6. AI -> AI is a human-approved single hop
7. Never auto-delete or auto-summarize on context overflow

## Deliberately not implemented yet
- Full Project entity/database.
- Conversation history import.
- File/PDF/URL context.
- Autonomous AI-to-AI loops.
- Automatic context summarization.
