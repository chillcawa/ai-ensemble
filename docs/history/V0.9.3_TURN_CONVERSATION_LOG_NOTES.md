# AI Ensemble v0.9.3 — Turn-based Conversation Log

## 目的
Conversation Historyを単純なmessage縦積みから、観測単位として読み返しやすいTurn表示へ変更。

## Turn
- User messageから次のUser message直前までを1 Turnとしてまとめる。
- Handoff requestも人間承認された新しい入力なので独立したTurnとして扱う。
- Context Reload markerはTurnに含めず、Turn間の境界として表示する。
- 最新Turnは常に展開。
- 過去TurnはConversationを開いた時点では折りたたみ。
- ユーザーが開いた過去Turnは、そのConversationを表示中は維持する。

## Turn header
- Turn番号 / 最新表示
- User質問の短いpreview
- AI回答数
- Cross-AI / AI参照あり / Handoff indicator
- timestamp

Observationの正式分類は各Assistant messageの既存badgeに残す。Turn headerのindicatorは概要のみ。

## Smart Scroll
- 読者が画面下部付近にいる時だけ、新着に自動追従。
- 過去を読んでいる時は勝手にscrollしない。
- 代わりに `↓ 最新Turnへ` を表示。

## Context Reload
Reload markerは通常message cardではなく、細い区切り線 + compact labelとして表示。
`履歴保持` と `以前の履歴を参照しない` の意味は従来どおり。

## データモデル
SQLite schema変更なし。Turnは保存フィールドではなく、既存Conversation MessagesからUIで導出する。
状態の二重管理を避ける。
