# v0.9 hotfix1 — Project list lifetime fix

Windows/Rust実ビルドで発生した `E0597` を修正。

## 原因
`list_projects()` の末尾式で `stmt.query_map(...).collect(...)` をそのまま返していたため、
`MappedRows` の一時値が `stmt` / `conn` より後にdropされる可能性があるとborrow checkerに判定された。

## 修正
中間値を明示的に分離:

- `rows = stmt.query_map(...)`
- `projects = rows.collect(...)`
- `Ok(projects)`

これにより `rows` が関数末尾の一時値にならず、`stmt` / `conn` のborrow寿命が明確になる。

npm/typecheck/build側には変更なし。
