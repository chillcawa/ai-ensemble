# v0.8.1 hotfix1 — Context Set isolation

## 症状
Context Set A/Bを切り替えてもProject/AI-specific Instructionが同じ内容になる場合がある。

## 原因
v0.7.6〜v0.8.1の新規Set作成処理が、その時点で有効なpersistent item IDを全て新Setへコピーしていた。
そのためA/Bが同じInstructionオブジェクトIDを共有し、Bを編集するとAも同時に変わって見えた。

## 修正
- 新規Context Setは空のSetとして作る。コピーしたい場合は明示的に「複製」を使用。
- Set複製時、Referenceは共有可能だがProject/slot Instructionは新IDへdeep clone。
- 旧版ですでに複数Setが同じInstruction IDを共有している場合、起動時に自動修復してSetごとに独立clone。
- Global/Sessionは従来通りSet外。

## 期待動作
Set Aに「A専用」、Set Bに「B専用」を保存し、切り替えるとそれぞれ別内容が表示・送信される。
