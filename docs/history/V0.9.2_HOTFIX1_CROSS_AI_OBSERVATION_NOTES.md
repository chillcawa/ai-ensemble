# AI Ensemble v0.9.2 hotfix1 — AI-Referenced Observation Provenance

## 原則 8
**AI-Referenced Observation ≠ Independent Observation**

AI由来Archiveを参照した観測は、Self / Cross-AI / Source Unknown のいずれであっても独立観測とは扱わない。ラベルは影響を根絶する防壁ではなく、観測条件を保存・可視化するための緩和策。

## 導出方式
手動の `isCrossAI` フラグは追加しない。回答時点の immutable source snapshot と Context Reload(reset) 境界から観測区分を導出する。

- Independent
- Self-Referenced
- Cross-AI
- AI-Referenced / Unknown

影響は reset 境界まで推移的・単調に伝播する。AI Archive ReferenceをOFFにするだけでは独立に戻らない。

## Source snapshot
Archive側のMirror mappingは変更可能だが、Context Libraryへ昇格した時点で source identity をContextへコピーする。さらにAI回答を保存する時点で `applied_ai_reference_sources` を conversation_messages にJSON snapshotとして固定する。

後からArchive mapping、Contextタイトル、Context自体を変更/削除しても、過去の回答分類は遡って変更しない。

## Archive review state
Import Archiveは `candidate`。人間がメッセージを選んでContext Libraryへ昇格した時に、そのContext Itemを `approved` とする。Import ≠ Contextを維持。

## Mirror identity
現時点は slotId 基準。
- source slot == target slot → Self-Referenced
- source slot != target slot → Cross-AI
- source slot不明 → AI-Referenced / Unknown

同一provider/modelの別slotを将来別カテゴリにする可能性は保留。ただし provider/model/slotId/nickname はsnapshotへ保存するため後から導出可能。

## OFF導線
imported_conversation ReferenceをOFFにすると確認UIを出す。
- 参照だけOFF
- OFFして独立観測へ戻る

後者は Reference OFF + `context_reload_reset` を1アクションで実行する。

## 必須テスト
1. Independent回答
2. Cross-AI Reference ON
3. Cross-AI回答
4. ReferenceだけOFF
5. 2回以上質問 → Cross-AI影響が継続
6. OFF + 独立観測へ戻る
7. 次の回答 → Independent
8. Archive mappingを後から変更しても過去バッジが変わらない
