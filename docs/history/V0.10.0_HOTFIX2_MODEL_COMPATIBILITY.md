# v0.10.0 hotfix2 — Kimi / Gemini Model Compatibility

SettingsでKimi/Geminiのモデルが「現在未対応」と見えるケースを修正。

## Important correction
2026-08-15時点の公式Kimi Model Listでは:
- `kimi-k3` = latest / flagship
- `kimi-k2.7-code-highspeed`
- `kimi-k2.6`

`kimi-k2` series（旧K2 preview群）はdeprecated。
前回会話で「K2.6が最新」と説明したのは誤り。K3実装は維持する。

## Changes
- Kimi Chat adapter allow-list:
  - kimi-k3
  - kimi-k2.7-code-highspeed
  - kimi-k2.6
- Gemini Chat adapter allow-list:
  - gemini-3.7-flash
  - gemini-3.6-flash
  - gemini-3.5-flash
  - gemini-3.5-flash-lite
  - gemini-3.1-flash-lite
  - gemini-2.5-flash
  - gemini-2.5-flash-lite
  - gemini-2.5-pro
- planned-era / stale localStorage model IDは、起動時にcurrent curated fallbackへ戻す。
- Settings表示:
  `（現在未対応）` → `（このAdapterでは未対応）`
  とし、Billing状態との混同を避ける。

## Billing boundary
Adapter support ≠ Billing status.
カード登録の有無によって「Adapter未対応」になることはない。
