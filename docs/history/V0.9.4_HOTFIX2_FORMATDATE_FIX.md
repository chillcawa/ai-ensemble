# v0.9.4 hotfix2 — ContextLibrary formatDate fix

Windows `npm run typecheck` で:

`Cannot find name 'formatDate'`

が発生。

原因:
Timezone対応時に ContextLibrary 内の旧 `formatDate()` helper を削除したが、
一覧表示の1箇所だけ旧呼び出しが残っていた。

修正:
`formatDate(item.updatedAt)`
→ `formatDateTime(item.updatedAt, timeZone)`

Timezone表示方針に統一。
