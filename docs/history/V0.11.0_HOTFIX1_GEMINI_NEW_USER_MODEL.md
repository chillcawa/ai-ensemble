# v0.11.0 hotfix1 — Gemini new-user model fallback

## Symptom

`gemini-2.5-flash-lite` がModel Discoveryに残っている一方、新規ユーザーの
実送信ではGoogle APIが404を返す場合がある。

## Fix

- `gemini-2.5-flash-lite` を現在のAdapterでは選択不可として表示。
- モデル一覧更新時、保存済みの同モデルを保持せず、先頭の利用可能な現行モデルへ移動。
- 推奨移行先は `gemini-3.5-flash-lite` 以降。

## Windows verification

1. Geminiの「モデル一覧を更新」を押す。
2. 選択モデルが `gemini-3.7-flash` 等の利用可能な3.x系へ切り替わることを確認。
3. Geminiへ実送信する。
