# v0.9.8 hotfix1 — Official Usage / Billing Links

Usage / Cost画面に各Provider公式の確認導線を追加。

Live Provider:
- OpenAI: API Usage / Billing
- Anthropic: Claude Console
- DeepSeek: DeepSeek Platform

Provider Registryに:
- `officialUsageUrl`
- `officialBillingUrl`
を追加。将来ProviderをLive化した時も同じUIを自動生成できる。

外部URLはTauri側の `open_official_provider_url` からOSブラウザで開く。
任意URLを開けないよう、公式Provider hostをwhitelistしている。

表示上も:
`Estimated Cost ≠ Billed Cost`
を維持し、AI Ensembleの推定値と公式請求を混同しない。
