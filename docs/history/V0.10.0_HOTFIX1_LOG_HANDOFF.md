# v0.10.0 hotfix1 — Handoff from Conversation Log

過去Turnの通常AI回答から、既存の1-hop Handoffを再実行できるようにした。

## UX
Conversation LogでTurnを開くと、各 `kind=normal` assistant回答に:

`⇢ 他AIへ渡す`

を表示。

押すと既存Handoff Modalが開き:
- 批判
- 検証
- 改善
- 要約
- 自由入力

を使って、現在API keyが設定されている他Mirrorへ送れる。

## Provenance
過去レスをHandoffする際も以下を保存/参照:
- historical source message id
- historical provider
- historical model
- historical nickname
- original Turn question

現在そのslotで別modelを選んでいても、Source Metaには過去回答を生成したmodel idを残す。

## Important boundary
`Handoff response → Handoff` は許可しない。

Conversation Logのボタンは `assistant + kind=normal` のみに表示し、
`kind=handoff` の1-hop responseには表示しない。
これにより人間承認1ホップの既存不変条件を維持する。

Handoff from Log ≠ Autonomous loop.
