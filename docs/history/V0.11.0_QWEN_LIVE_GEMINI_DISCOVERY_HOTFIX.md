# v0.11.0 — Qwen Live + Gemini Discovery Hotfix

## Gemini hotfix

- Model Discoveryが返す `models/gemini-*` 形式をplain model IDへ正規化。
- capability判定もresource-nameの最終segmentを使う。
- 通常会話用Geminiが表示上だけ「このAdapterでは未対応」になる経路を修正。

## Qwen Live

- Alibaba Cloud Model Studio / Qwenを6番目のLive Providerとして追加。
- Singapore InternationalのOpenAI互換Chat Completionsを使用。
- 通常送信、streaming、model discovery、Credential Store、token usage記録に対応。
- 初期モデル: `qwen3.7-plus` / `qwen3.6-flash`。
- VL / Omni / Audio / Realtime / Embedding等の専用モデルはChat adapter対象外。

## Billing boundary

- 無料枠はSingapore Internationalの対象モデルのみ。
- 無料枠の有効期限・残量・Free Quota Only設定はAPI応答から判別できない。
- Qwenのローカル推定額は表示せず、Model Studioの公式Usage/Billing確認へ誘導。
- `Estimated Cost ≠ Billed Cost` を維持。
