# v0.10.0 — Gemini Live

5鏡目としてGoogle GeminiをLive化。

## API surface
Google公式OpenAI compatibility layerを利用:
- Chat Completions: `https://generativelanguage.googleapis.com/v1beta/openai/chat/completions`
- Model Discovery: `https://generativelanguage.googleapis.com/v1beta/openai/models`
- Bearer `GEMINI_API_KEY`
- Streaming対応

## Default
`gemini-3.7-flash`

2026-08時点のstable Flashモデル。
1,048,576 input token / 65,536 output token。
Free Tierあり。

Fallback:
- gemini-3.6-flash
- gemini-3.5-flash-lite

## Cost boundary
Gemini API responseだけでは、そのAPI keyのprojectがFree TierかPaid Tierか判別できない。
そのためv0.10.0ではGeminiのtoken usageは記録するが、local `cost_usd` は空にする。

`Free Tierで$0なのにPaid list-priceを請求額のように表示する` 誤解を避けるため。

公式の最終確認先:
Google AI Studio Dashboard > Usage / Billing。
