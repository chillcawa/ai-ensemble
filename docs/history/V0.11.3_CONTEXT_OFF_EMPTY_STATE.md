# v0.11.3 — Context-off empty state

`Setなし（Context無効）` の表示と実際の送信状態を一致させる。

## UI

- SetなしではInstruction見出しだけ表示し、全入力欄を非表示。
- SetなしではReference見出しだけ表示し、件数・filter・一覧を非表示。
- Context Set領域とPrimaryの `＋ 新規作成` は表示を維持。
- Setを選択するとInstruction／Reference UIを復元。

## Request semantics

- SetなしではGlobal / Project / slot / Sessionを含む全Contextを送信しない。
- Context Itemの保存データ自体は削除・変更しない。
- Setを再選択すると保存内容が復元される。
