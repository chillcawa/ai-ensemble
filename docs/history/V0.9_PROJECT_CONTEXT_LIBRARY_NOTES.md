# AI Ensemble v0.9 — Project + Context Library

## 目的
Conversation / Context Setの上にProject境界を追加し、再利用する資料をContext Libraryへ保存する。
Persistent Context / Context Set / 選択状態はlocalStorageからSQLiteへ移行する。

## Project
- SQLite `projects` テーブル
- 既存データ用の `Workspace` (`workspace-default`) を自動作成
- Conversationに `project_id` を追加
- 左Conversation Sidebarは選択中Projectの会話だけ表示
- Project作成 / 名前変更 / 削除
- Project削除時、ConversationはWorkspaceへ移動
- Project固有Context / Context SetはUI側で削除

## Context SQLite移行
- `context_state` テーブルへJSONとして保存
  - Persistent Context Items
  - Context Sets
  - ConversationごとのContext Set選択
- pre-v0.9のlocalStorageデータはSQLiteが空なら一度だけ移行
- Session Contextは従来通り永続化しない
- API Keyは引き続きOS Credential Store

## Context Library
- Project単位のPersistent Reference一覧
- 検索
- 有効 / 無効
- 選択中Context Setへ追加 / 除外
- 削除
- Referenceごとの概算token表示

## File Context v1
対応:
- TXT
- Markdown (.md / .markdown)
- PDF（埋め込みテキスト抽出のみ）

PDF抽出はRust側 `pdf-extract` を使用。
画像ベースPDF / OCR / 複雑レイアウトや表構造の完全再現は未対応。
ファイル上限は20MB。

## Context境界
- Global: 全Project
- Project / slot persistent Context: 所属Projectのみ
- Context Set: Project所属
- Session Context: Conversationのみ
- Project切替時にConversation / Context Set / Project Referenceが混ざらない

## 既存原則
1. Instruction != Reference
2. Import != Context
3. Context追加 != 永続保存
4. Context保存 != 即時送信
5. AI Response != System Prompt
6. AI -> AI = 人間承認1ホップ
7. Context超過時に自動削除 / 自動要約しない
