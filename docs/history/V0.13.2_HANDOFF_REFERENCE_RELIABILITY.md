# AI Ensemble v0.13.2 — Handoff reference reliability

The Handoff payload already contains the complete source answer as a Reference,
but payload inclusion does not guarantee that the receiving model will read,
quote, or reason from it faithfully.

## UI clarification

- The Handoff dialog states that the complete Reference is transmitted while
  provider-side comprehension and citation are not guaranteed.
- Result cards now say `Referenceとして送信済み（追従保証なし）` rather than
  implying that successful completion proves the model used the source.
- No provider is hard-coded as incompatible. Reliability can vary by model,
  prompt, context length, and provider behavior.

## Reference verification preset

A new `参照確認` preset asks the receiving AI to quote the first 20 characters
of the source answer before analyzing it, or explicitly answer `参照なし`.
This is a practical observation aid, not a cryptographic proof of attention.
