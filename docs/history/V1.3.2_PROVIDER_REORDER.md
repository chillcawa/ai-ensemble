# AI Ensemble v1.3.2 — Provider reorder

## User-visible change

Target AI cards can be reordered from the send-target slider.

- Desktop: drag the `⠿` handle and drop the card at another AI position.
- Keyboard/tablet fallback: use the left and right arrow buttons on each card.
- The same order is used by broadcast sending, result columns, and AI Navigation.
- The order persists across launches and is included in export/restore through the existing `providerSlots` array order.

## Safety behavior

The stored order is normalized against current slot IDs. Unknown and duplicated IDs are ignored, while providers introduced by a newer build are appended in their canonical default order. Provider identity and response routing continue to use stable `slotId` values rather than array indexes.
