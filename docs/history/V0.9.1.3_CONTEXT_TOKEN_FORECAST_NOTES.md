# v0.9.1.3 Context Token Forecast

- Context Set選択欄の選択中Setだけ、未更新Instruction draftを含む概算tokenへリアルタイム更新。
- Context画面に「Set本体」と「現在の適用量」を分離表示。
- Set本体: 選択Set内のProject/AI別Instruction + Reference。Global/Sessionは含まない。
- 現在の適用量: Global + 選択Set + Session + AI別Instruction/Reference。
- 未更新Instructionがある場合は「未更新を反映」と明示。
- 他のSetの選択肢は保存済み値を表示。
- 送信時の予測値（履歴 + 質問を含む）は従来ロジックを維持。
