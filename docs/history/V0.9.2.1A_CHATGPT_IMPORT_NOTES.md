# AI Ensemble v0.9.2.1a — ChatGPT Conversation Export Adapter

## 目的
汎用JSON Importの前段にChatGPT export専用Adapterを追加し、`conversations.json` / 分割されたconversation JSONをArchiveへ正規化する。

## ChatGPT export検出
`mapping` を持つConversation objectをChatGPT exportとして検出する。

OpenAI公式ヘルプでは、データexportにChat historyが含まれ、account間移行手順では`conversations.json`を利用すること、規模の大きいexportでは番号付きconversation JSONに分かれる場合があることが案内されている。

## Branchの扱い
ChatGPT exportの`mapping`は分岐を持ち得るため、v0.9.2.1aでは:

1. `current_node`が存在すれば、そのnodeからparentを辿ってrootまで復元
2. `current_node`が欠ける場合は、最新timestampを持つleafをfallbackとして選択
3. Archiveにはその1本のactive pathだけを保存

分岐全体を複数Archiveへ展開する機能はまだ実装しない。

## Message変換
- user/human → user
- assistant → assistant
- system/developer → system
- その他 → unknown
- `message.content.parts`からテキストを抽出
- create_timeをISO文字列へ変換
- assistant metadataの`model_slug`を可能ならconversation-level `sourceModel`へ保存
- `sourceProvider = openai`
- `source = chatgpt-export`

画像・音声・tool payloadそのものをraw JSONとしてArchive本文へ混ぜることはしない。現段階ではテキスト部分のみ。

## Provenance
Import直後は従来どおりArchive candidate。
Context Libraryへユーザーが明示昇格した時だけapproved Referenceになる。

## Context Set表示
`手動 / Setなし` を `Setなし（Context無効）` に変更。
補足として、SetなしでもGlobal / Sessionは引き続き適用されることを明示。
