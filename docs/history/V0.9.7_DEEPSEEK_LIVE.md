# v0.9.7 — DeepSeek Live

AI Ensemble初の第三Provider実接続。

## 実装
- DeepSeekをProvider Registryで `Runtime: Live`
- OS Credential StoreへのDeepSeek API key保存
- `https://api.deepseek.com/chat/completions`
  - non-streaming
  - streaming SSE
  - usage token取得
- `https://api.deepseek.com/models`
  - model discovery
- fallback catalog:
  - deepseek-v4-pro
  - deepseek-v4-flash
- 1M contextをcurated metadataとして保持
- DeepSeek slotを追加
- 既存ユーザーの2カラム幅localStorageにも3列目を420pxで安全に補完

## 意図的に未実装
### DeepSeek cost
v0.9.7ではDeepSeekのUSD costをハードコードしない。

理由:
- input価格がcache hit / cache missで異なる
- 2026-08-16からpeak / off-peak料金へ変更予定
- 現在のAI Ensemble cost schemaは入力tokenを1種類として扱っており、
  ここで単一価格を入れると「推定値」を正確そうに見せてしまう

API usage token自体はSQLiteへ保存する。
次段で cache-aware + time-aware pricing を設計する。

## DeepSeek thinking mode
DeepSeek V4はthinking modeがdefault。
APIが返す `reasoning_content` はv0.9.7では保存・表示しない。
Conversation Logにはfinal `content` だけを第一級レスポンスとして保存する。

## Provider境界
DeepSeekがLiveになっても:
- Import AdapterはGeneric fallback
- Responses APIはまだ使わない
- toolsをAI Ensembleから自動実行しない

Runtime / Import / Tools / Pricingを一括で「対応済み」にしない。
