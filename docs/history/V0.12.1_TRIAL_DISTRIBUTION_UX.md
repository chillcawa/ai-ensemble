# AI Ensemble v0.12.1 — Trial distribution UX

## Added

- A mandatory first-run Preview notice with explicit acknowledgement.
- Clear notice that prompts are sent to selected external AI providers.
- Warnings covering API keys, provider billing/free tiers, confidential data,
  model accuracy, and user responsibility.
- A Settings action to display the notice again.
- Current application version in the header and Settings.
- User-facing translations for common provider errors:
  - rate/quota limit (`429`)
  - API-key/authentication (`401`)
  - permission/plan/region (`403`)
  - retired or unavailable model (`404`)
  - provider outage/overload (`5xx`)
  - network timeout
- Error isolation wording confirms that other AI responses continue.

## Public terminology

The personal term `Mirror` was removed from user-facing navigation, tooltips,
and archive mapping labels. Distribution-facing UI now uses `AI` consistently.

## Deliberately not added

- No automatic telemetry.
- No automatic feedback submission.
- No external feedback URL until the owner selects a destination.
- No claim that a free tier prevents all provider-side usage or data handling.

The notice acknowledgement is stored locally under a versioned notice key. It
does not transmit consent or usage information anywhere.
