# AI Ensemble v0.8.0 — Capability-first Models

## 目的
モデル名そのものではなく、能力メタデータを基準にモデルを扱う土台へ移行。

## 追加
- ApiMode: chat_completions / responses / messages
- CapabilitySource: provider_metadata / curated / inferred / unknown
- PerformanceClass: frontier / balanced / fast / unknown
- ModelCapabilities:
  - streaming
  - vision
  - tools
  - audio input/output
  - max context tokens
  - supported API modes
  - preferred API mode
  - current adapterで利用可能か
  - 未対応理由
  - capability metadataの出所
  - performance class

## UI
- モデル選択ポップオーバーにCapability badge
- 現在未対応のモデルも確認可能。ただし選択不可
- Responses APIが必要なモデルは理由を表示
- Providerカードに主要Capabilityを表示
- 設定画面にもCapability表示
- 推奨欄にもCapability表示

## 推薦
推薦ロジックはモデルID文字列を直接解析せず、構造化された
performanceClass / tools / streaming / maxContextTokens / availableNow
を評価する。

## 注意
/v1/models がVision/Tools等を完全なCapability metadataとして返すとは限らないため、
v0.8.0では一部を inferred として保持し、UIでも推定であることを明示する。

OpenAI Responses APIの実送信Adapterはまだ未実装。
v0.8.1で実装予定。
