# AI Ensemble v1.3.0 — macOS trial and tablet-width UI

## macOS trial build

- Added a macOS platform configuration for `.app` and `.dmg` bundles.
- Uses ad-hoc signing for trial distribution without Apple Developer secrets.
- Added a manually triggered GitHub Actions workflow.
- The workflow builds separate Apple Silicon and Intel DMG artifacts.
- Windows keeps the existing NSIS bundle configuration.

## Tablet-width and touch layout

- The conversation sidebar becomes an overlay below 1024 px while its collapsed rail remains available.
- Provider and result lanes use mandatory horizontal snap scrolling.
- Result resizing is disabled at tablet widths in favor of one-card-at-a-time navigation.
- Header, settings, dialogs, and result actions reflow for narrow windows.
- Coarse-pointer controls use larger touch targets and do not hide conversation actions behind hover.

## Trial limitation

The DMGs are ad-hoc signed and not notarized. macOS may require the tester to allow the app from Privacy & Security before first launch.
