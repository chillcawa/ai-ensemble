# AI Ensemble v0.6.2

## Fix
- `/v1/models` is treated as an inventory, not a guarantee of compatibility with the current streaming adapter.
- OpenAI specialized / non-streaming families such as `*-pro`, Codex, deep-research, realtime, audio, image, etc. are excluded from the current model selector.
- A backend guard prevents a stale/invalid saved model from reaching the Chat Completions streaming adapter.
- OpenAI GPT-5.x reasoning-family requests use `max_completion_tokens` and omit legacy `temperature`.
- Current OpenAI frontier chat models such as GPT-5.6 / GPT-5.6 Sol / Terra / Luna can therefore be selected when the API key exposes them.
- Pricing entries for the GPT-5.6 family were added.

## Design direction
The next larger step is a dedicated OpenAI Responses API adapter. That will allow models that are intentionally excluded from the current Chat Completions streaming path, including Pro/specialized models where supported.
