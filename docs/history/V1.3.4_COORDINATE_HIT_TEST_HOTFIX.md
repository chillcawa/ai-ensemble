# AI Ensemble v1.3.4 — Coordinate hit-test hotfix

In the Windows Tauri WebView, pointer capture successfully activated the drag handle, but `document.elementFromPoint()` did not reliably identify the provider card under the captured pointer. The source card became translucent while no valid destination was committed.

The drop target is now selected by comparing the live pointer coordinates with every provider card's `getBoundingClientRect()` result. The target is recalculated once more on pointer release before applying the persisted slot order.
