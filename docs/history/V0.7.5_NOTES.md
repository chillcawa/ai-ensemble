# AI Ensemble v0.7.5 — Conversation Persistence + Model Shortcut

## Conversation persistence

- SQLiteに `conversations` / `conversation_messages` を追加。
- 最初の質問送信時にConversationを自動作成。
- 通常のUser Messageと各AI Responseを保存。
- 再起動時には最終更新Conversationを自動で再オープン。
- Conversation選択 / 新規Conversation開始に対応。
- 通常会話を次回送信時のhistoryとして各slotへ再投入。
  - user messageは共有。
  - assistant responseは同一slotのものだけを履歴に含める。
  - 他AIの回答はHandoff/Contextを使わない限り暗黙共有しない。
- Handoffは `handoff_request` と `handoff` として保存し、元Responseへの関係を `parent_message_id` で追跡。
- Handoff履歴は通常会話historyには自動混入させない。
- AI Responseにはprovider/model/slot/nickname/usage/cost/appliedContextIdsを保存。

## Model shortcut

同じModel Pickerを次の2箇所から開ける。

1. 推薦欄の `現在選択中 ▾`
2. 各AI回答フレーム右上の `model-id ▾`

Model Pickerでは現在モデルと推奨モデルを表示し、選択時のみ切り替える。モデル切替だけでは送信しない。

## v0.7 Context原則との整合

Conversation historyはContext Referenceとは別物として扱う。
AI Aの通常回答がAI Bのhistoryへ暗黙混入することはない。
AI間共有は従来通り、人間承認のHandoffまたは明示的Context追加による。
