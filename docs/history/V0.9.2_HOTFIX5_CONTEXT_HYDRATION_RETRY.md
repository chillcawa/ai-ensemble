# v0.9.2 hotfix5 — Context Hydration Retry

## 症状
hotfix3/4でSQLite hydration完了までContext UIをロックした結果、
hydrationが1回でも失敗するとContextが「反応しない」ように見える状態になった。

## 修正
- Context/Project SQLite読み込みを `Promise.all` から逐次読み込みへ変更
  - 複数Connection同時openを避ける
  - エラー発生箇所を追いやすくする
- hydration失敗時も古いlocalStorageへfallbackしない
- 失敗時はContextボタンを「Context再読込を再試行」に変更
- 画面上にも「再試行」ボタンを表示
- retry時はSQLiteから完全に再hydration
- 成功した時だけContext UI/送信を解放

## 維持する安全原則
SQLite = runtime source of truth.
localStorage = pre-v0.9 one-time migration source only.

## 実機確認
1. 起動
2. `Context読込中…` → `Context` へ変わる
3. Contextを開ける
4. もしエラーなら表示されたエラー文を確認し「再試行」
5. 再試行成功後、Contextを開く
