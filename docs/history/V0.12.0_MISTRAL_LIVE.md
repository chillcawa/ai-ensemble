# AI Ensemble v0.12.0 — Mistral Live

## Priority decision

Mistral was implemented before xAI/Grok. Mistral offers a low-rate-limit Free
mode intended for testing and prototyping, while live Grok API requests require
paid API usage. This keeps the seventh-mirror validation possible without first
adding another paid provider.

## Added

- Mistral API key storage through the existing OS credential-store boundary.
- Official `POST /v1/chat/completions` adapter.
- Streaming SSE responses and token usage capture.
- Official `GET /v1/models` discovery.
- Filtering by Mistral's `capabilities.completion_chat` metadata when present.
- Curated fallback models:
  - `mistral-small-2603` (default)
  - `ministral-8b-2512`
  - `mistral-medium-3-5`
- Seventh enabled provider slot in the main grid.

## Billing display policy

Inference responses do not identify whether the API key belongs to Free or
Scale mode. AI Ensemble therefore records token counts but does not invent a
cost estimate; the usage row points the user to Mistral Admin for confirmation.

## Windows validation

1. Run `npm run typecheck` and `npm run build`.
2. Run `npm run tauri:dev`.
3. In Settings, save a Mistral API key.
4. Confirm model discovery completes and selects a chat-capable model.
5. Send once to Mistral only, then send to all seven mirrors.
6. Confirm streaming text, completion status, token counts, and uninstall/
   reinstall credential behavior.

Grok remains a planned provider and is the next adapter candidate once paid API
validation is acceptable.
