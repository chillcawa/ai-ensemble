# AI Ensemble v0.8.1 — OpenAI Responses API Adapter

## 実装
- OpenAI `POST /v1/responses` の非Streaming送信
- Responses SSE streaming (`response.output_text.delta`, `response.completed`, error)
- Responses usage (`input_tokens` / `output_tokens`) を既存Usage/Cost SQLiteへ統合
- System系メッセージは `instructions` に正規化
- user/assistant履歴は Responses `input` へ変換
- `max_output_tokens` / temperature の差分をAdapter内で吸収
- TypeScript→Tauriへ `apiMode` を明示して、Chat Completions / ResponsesをRust側でrouting

## Capability / Model Discovery
- `*-pro` 系は Responses経由で利用可能に変更
- Pro系はStreaming非対応として扱い、Orchestratorが自動的に非Streamingへfallback
- deep-research / computer-use / search-preview / codex はResponsesを使うが、専用tool/agent workflowが必要なため引き続き選択不可
- dual-modeの通常GPTは既存互換性を優先し、現時点ではChat Completionsをpreferredのまま維持

## Cost
- `gpt-5.5-pro` の料金を pricing.json に追加
- Responsesのusageも既存pricing calculatorへ渡す

## 意図的に未実装
- Web search / File search / Code Interpreter等のResponses tools
- Background mode
- Responses Conversations APIによるserver-side会話状態
- dual-modeモデルでのAPI mode手動切替

AI Ensemble側のConversation/Contextを引き続きsource of truthとし、OpenAI側のconversation stateへ自動移行しない。
