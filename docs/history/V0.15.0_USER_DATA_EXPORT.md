# AI Ensemble v0.15.0 — User data export

- Added a Settings button that exports user data to one JSON file in Downloads.
- Exports an explicit allowlist of SQLite user-data tables, including conversations, responses,
  Context state, Projects, imported archives, Usage, observations, and Text Pad
  documents.
- Exports an explicit allowlist of frontend preferences and provider display
  settings.
- API keys, key-presence flags, and unsaved key drafts are excluded.
- The export records that Credential Store keys are excluded and that free-text
  content is not automatically redacted.
- Export is read-only. Import/restore is intentionally not part of this version.
