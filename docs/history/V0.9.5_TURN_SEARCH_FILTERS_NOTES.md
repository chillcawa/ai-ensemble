# v0.9.5 — Turn Search / Filters

Conversation Logを「原文を探して読む」ための最小検索機能。

## 実装
- 全文検索
  - User / AI の原文を対象
  - nickname / provider / model も検索対象
  - 大文字小文字を区別しない
  - 検索中は一致Turnを一時的に展開
  - 原文そのものは変更せず、該当箇所だけ表示上ハイライト
- Observation filter
  - Independent
  - Self-Referenced
  - Cross-AI
  - AI-Referenced / Unknown
  - AI参照あり（non-independent）
- Handoff filter
  - あり / なし
- フィルタ中は一致Turn数を表示
- フィルタ中はContext Reload boundaryを非表示（Turn検索対象ではないため）
- クリアで通常ログへ即時復帰

## 非実装
- AI要約
- 自動差分抽出
- 重要度ランキング
- semantic search / embedding
- 検索結果による原文の再構成

原則:
Comparison Aid ≠ Comparison Conclusion
Search Aid ≠ Relevance Judgment

検索は文字列一致と既存provenance/Observation metadataだけを使い、
「何が重要か」は判定しない。
