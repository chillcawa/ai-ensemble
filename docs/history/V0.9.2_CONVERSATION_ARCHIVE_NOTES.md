# AI Ensemble v0.9.2 — Conversation Archive

## 原則
Import ≠ Context。
外部会話を取り込んだだけではAIへ送信しない。ArchiveはProject単位でSQLiteに保存し、ユーザーが選んだメッセージだけをContext LibraryへReferenceとして昇格する。

## 実装
- Project Barに `Conversation Archive`
- JSON / Markdown / TXTの汎用Import
- Archive / MessageをSQLite保存
- Archive検索、会話選択、メッセージ単位チェック
- 全選択 / 解除
- 選択範囲の概算token表示
- `選択範囲をContext Libraryへ`
- Archive削除
- Archive削除後も、すでにLibraryへ昇格したReferenceは保持

## Contextへ昇格した際の型
- kind: conversation
- role: reference
- scope: project
- lifetime: persistent
- provenance: imported_conversation
- reviewState: approved
- editedByUser: false

ユーザーが明示的に選択してLibraryへ保存した時点をapprovedとする。Libraryへ保存してもContext Setには自動追加しない。

## 汎用Import v0.9.2
JSON:
- `[ { role, content }, ... ]`
- `{ title, source/provider, messages: [...] }`
- `{ conversations: [ { title, messages: [...] }, ... ] }`

Markdown / TXT:
- `User:` / `Human:` / `Assistant:` / `AI:` / `System:`
- Markdown見出し `## User` 等も認識
- role markerがなければファイル全体をunknown 1メッセージとしてArchiveする
