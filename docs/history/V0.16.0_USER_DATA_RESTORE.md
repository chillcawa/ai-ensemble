# AI Ensemble v0.16.0 — User data restore

- Moved Trial information and Data transfer to the bottom of Settings.
- Added JSON file selection and restore for v0.15+ user-data exports.
- Restore fully replaces conversations, responses, Context state, Projects,
  imported archives, Usage, Text Pad documents, and exported preferences.
- Credential Store API keys are neither imported nor deleted.
- The UI validates the export format, required tables, and preference structure
  before showing the destructive confirmation.
- The native restore validates table/column allowlists, uses parameterized
  inserts, and wraps the entire replacement in one SQLite transaction.
- Restore failure rolls back database changes. Successful restore reapplies the
  exported frontend preferences and reloads the application.
- Provider enabled/disabled state is now persisted so it can be migrated.
