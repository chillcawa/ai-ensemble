# AI Ensemble v1.2.0 — 简体中文 / 한국어

## 追加内容

- 簡体字中国語と韓国語を言語選択へ追加
- `zh-CN` / `zh-SG` / `zh-Hans` と韓国語OSの自動判定
- 言語設定のバックアップ・復元対応
- 未翻訳キーを英語へ戻すフォールバック

## 方針

主要操作の文言は簡体字中国語・韓国語へ翻訳しています。低頻度の説明文や診断文で未翻訳の
ものは、日本語ではなく英語で表示します。質問、回答、Context本文、利用者が付けた名前、
Providerのエラー本文は原文を維持します。

中国語は現段階では簡体字のみです。繁体字中国語は別localeとして後から追加します。
ヒンディー語は優先度を下げ、余裕ができた段階で検討します。
