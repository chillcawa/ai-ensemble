# AI Ensemble v0.5 実装メモ / 2026-08-13

v0.4を基に、以下を実装。

## 実装済み
- ダーク / ライト / システム外観
- AI表示名（ニックネーム）のローカル保存
- 送信前の概算コスト表示
  - 入力トークンは文字数からの簡易推定
  - 最大出力1024 tokensとして「最大概算」を表示
  - 実際の請求額ではなく目安
- AI回答カラム
  - AI数が増えても横スクロール
  - カラム境界をドラッグして幅変更
  - 最小幅280px
- 結果IDを provider:model に変更
- 料金表を src-tauri/pricing.json に分離
- USD/JPY表示を固定150円または手動設定に変更
- 設定パネル
- Provider / Model ID / 表示名をUI上で分離して扱う準備
- バージョンを0.5.0へ更新

## まだ未実装
- 自動為替取得
- Provider APIからモデル一覧を取得
- モデル選択UI
- 月別 / モデル別Usage集計
- Project Context

## 注意
この環境ではRust/Nodeの完全なビルドツールチェーンが利用できなかったため、ここでWindows用Tauri実機ビルドまでは検証していない。
元ZIPに含まれていた node_modules は不完全な状態だったため、配布ZIPには node_modules を含めない。
Windows環境で `npm install` → `npm run tauri:dev` を実行して確認すること。


# AI Ensemble v0.6 実装メモ / 2026-08-13

## 実装
- OpenAI / AnthropicのAPIキーを使ったモデル一覧取得をRust側へ追加。キーはOS Credential StoreからRust側だけで読み出す。
- Providerのチェックボックスを送信対象として利用し、選択数に応じて送信ボタン文言を変更。
- モデル選択を設定画面へ追加し、選択モデルIDをlocalStorageへ保存。
- 簡易テキストエディタをモーダルで追加。内容はlocalStorageへ自動保存。
- エディタへの貼り付けを検出し、直近30件をローカル履歴として保存。
- 貼り付け履歴をクリックしてエディタへ復元、エディタ内容を質問欄へ送信可能。

## 注意
OpenAIの`GET /v1/models`はAPIで利用可能なモデル一覧を返すが、一覧にはチャット以外のモデルが含まれる場合がある。v0.6では明らかに別用途のモデルを簡易除外し、最終的な利用可否は実際のAPI応答を優先する。Anthropicの`GET /v1/models`はAPIで利用可能なモデルを返し、最大1000件を取得する。
