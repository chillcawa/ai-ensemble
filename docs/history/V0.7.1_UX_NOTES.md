# AI Ensemble v0.7.1 UX notes

This release does not change the seven Context invariants. It is a stabilization/visibility pass over v0.7.

Changes:
- Context Reference deletion now uses the centered in-app ConfirmModal.
- Context summary separates active Instructions and active References.
- Reference filters: all / active / persistent / AI-generated.
- Reference cards show provenance, scope, and lifetime badges.
- Disabled Reference cards are visually de-emphasized.
- The composer shows a compact preview of active Context titles before send.
- Normal AI responses gain an explicit Copy action.
- One-hop Handoff results gain Copy and explicit `Contextに追加` actions.
- Handoff results remain terminal: no second-hop handoff control is exposed.
- Version metadata updated to 0.7.1.
- Added V0.7_STABLE_CHECKLIST.md for Windows/Tauri stable qualification.
