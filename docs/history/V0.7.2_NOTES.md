# AI Ensemble v0.7.2

## Model recommendation
- Global single-winner recommendation was removed.
- One recommendation is shown per configured AI slot/provider.
- Recommendation display can be toggled ON/OFF and the preference is persisted locally.
- Recommendations never change a model automatically; the user must press "このモデルに変更".
- Recommendation reasons are generated after the actual candidate is selected.
- When a short/simple question has no recognizable lightweight model in the provider catalog, the UI explicitly says it is using a fallback among currently available candidates.

## AI handoff provenance
- Handoff destination AI(s) remain explicitly user-selectable.
- The receiving AI receives the source response as Reference, not System/Instruction.
- Reference metadata now includes source nickname, provider, model, slotId and original question.
- Source AI metadata is visible in the Handoff modal and Handoff result UI.
- Source AI's applied Context is not automatically inherited by the receiving AI.
- One-hop rule remains unchanged; Handoff results do not expose automatic onward handoff.
