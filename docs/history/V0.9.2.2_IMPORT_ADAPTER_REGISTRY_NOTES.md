# AI Ensemble v0.9.2.2 — Import Adapter Registry

## 目的
Conversation Importの各社固有フォーマット対応を本体から分離し、Provider追加時にRegistryから対応する「翻訳機」を自動発見できる土台を作る。

## Registry
`src/archive/registry.ts`

Adapterは以下を宣言する:
- id / displayName
- dedicated / generic
- 対応Provider IDs
- priority
- 対応拡張子
- detect(probe) → confidence
- parse(probe) → AI Ensemble共通Archive

## 現在登録済み
Dedicated:
- ChatGPT Export → OpenAI
- Claude Export → Anthropic

Generic fallback:
- Generic JSON
- Generic Markdown
- Generic Text

## 自動判定
Import時に全Adapterへprobeし、confidence → priorityの順で最適Adapterを自動選択する。
Import後は実際に使った翻訳機名とconfidenceをUI表示する。

## Provider追加との接続
`providerImportSupport(providerId)` を通じて、Provider Slotが追加された時点で:
- 専用Adapterあり → 専用翻訳機を自動発見
- 専用Adapterなし → Generic fallbackを利用可能と表示

SettingsとProviderカードに対応状況を表示する。

## 重要
v0.9.2.2は「ローカルRegistryからの自動発見」。
インターネットから未署名コードを自動ダウンロードして実行する機能はまだ入れない。
将来Remote Adapter Catalogを作る場合も、署名/バージョン/ユーザー承認を前提に別段階で設計する。

## Context表示
`手動 / Setなし` を `Setなし（Context無効）` に変更。
Global / Session ContextはSet外という既存仕様は維持。

- Adapterを本体Archiveロジックに混ぜず拡張できる
