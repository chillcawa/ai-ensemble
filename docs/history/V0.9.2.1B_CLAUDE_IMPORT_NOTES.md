# v0.9.2.1b — Claude Conversation Export Adapter

## 実装
- Claude専用JSON Adapterを追加
- 汎用JSON parserより前にClaude形式を判定
- `chat_messages` / `chatMessages` を優先し、互換用に `messages` も受理
- sender/roleを user / assistant / system / unknownへ正規化
- `text` とstructured `content` blocksからテキストを抽出
- created_at / createdAt / timestampを保持
- model情報があればsourceModelへ保持
- sourceProvider=`anthropic`, source=`claude-export`
- Import直後はArchive candidate、Context昇格時のみapprovedの既存原則を維持

## 重要な互換性注記
Anthropic公式Help Centerは、Claudeのdata exportにconversation data/chat historyが含まれ、JSON conversation dataを扱えることを案内しているが、export JSONの完全な公開schemaは確認できなかった。
そのため本AdapterはClaude exportで使われる代表的なフィールドを許容的に読む互換Adapterであり、将来export schemaが変わればfixture追加とAdapter更新が必要。
