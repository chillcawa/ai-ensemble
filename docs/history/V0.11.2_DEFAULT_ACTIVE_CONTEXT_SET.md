# v0.11.2 — Default active Context Set

新しいProject／ConversationのContext初期状態を有効化。

## Behavior

- ProjectにContext Setがない場合、空の `Default` Setを自動作成して選択。
- 既存Setがあり、そのConversationに選択履歴がない場合、先頭Setを初期選択。
- ユーザーが明示的に `Setなし（Context無効）` を選んだ場合、保存された `null` を尊重。
- `Setなし` を自動的に別Setへ戻さない。

## Boundaries

- 既存Context ItemをDefault Setへ自動追加しない。
- 過去のSet内容・選択履歴を変更しない。
- Default Setの作成と選択はSQLiteへ通常どおり永続化。

## Windows check

1. 新しいProjectを作成する。
2. Contextを開き、`Default` が選択済みであることを確認。
3. `Setなし` を選び、画面を開き直して無効状態が維持されることを確認。
4. 新しいConversationで再びDefault／既存Setが初期選択されることを確認。
