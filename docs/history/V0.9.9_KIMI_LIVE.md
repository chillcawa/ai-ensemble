# v0.9.9 — Kimi Live

AI Ensemble 4鏡目として Kimi K3 をLive化。

## API
- Global Base URL: `https://api.moonshot.ai/v1`
- Chat: `/v1/chat/completions`
- Models: `/v1/models`
- Bearer API key
- Streaming SSE
- `stream_options.include_usage = true`

## Model
- `kimi-k3`
- 1,048,576 token context
- streaming
- vision
- tool calling capability
- always-reasoning model

AI Ensemble v0.9.9ではK3のみをLive対象とする。
Model Discoveryで他モデルが返っても、K3以外は現段階では実行不可表示にする。

## Reasoning boundary
K3は `reasoning_content` を別フィールドで返す。
AI EnsembleはConversationにfinal `content`だけを保存・表示する。

Moonshotはmulti-turnでcomplete assistant message（reasoning state含む）の保持を推奨しているため、
v0.9.9のKimi multi-turnは「final content historyのみ」という制約がある。
これは将来、provider-private stateをConversation原文から分離保存する設計で扱う候補。

## Cost
K3 standard price:
- cache hit input: $0.30 / MTok
- cache miss input: $3.00 / MTok
- output: $15.00 / MTok

API `usage.cached_tokens` をcache hitとして取得。
cache miss = prompt_tokens - cached_tokens。
Pricing Profile engineへ実測値を渡す。
