# v0.9.6 — Provider Registry Foundation

目的:
OpenAI / Anthropic の2社固定実装から、DeepSeek / Kimi / Qwen / Grok / Mistral等を
段階的に追加できるProvider Registry構造へ移行する。

## 今回やったこと
- `src/providers/registry.ts`
  - Provider ID
  - display name / default nickname
  - Runtime status
  - Chat / Streaming Adapter status
  - Model Discovery status
  - Credential Store status
  - API mode
  を一元管理。
- OpenAI / Anthropicだけ `Runtime: Live`
- xAI / DeepSeek / Kimi / Qwen / Mistralは `Runtime: Planned`
- Planned providerはAPIキー入力・送信対象には追加しない
- SettingsにProvider Registry一覧を追加
- Conversation Import Adapter状態もProvider Registry一覧に併記
- APIキー欄のProvider名もRegistry由来に統一
- UsageのProvider表示名もRegistry由来へ統一

## 重要な境界
`Registered Provider ≠ Usable Provider`

ProviderをRegistryに知識として登録しても、
Runtime AdapterがLiveになるまで送信可能とは扱わない。

同様に:
- Runtime Adapter
- Model Discovery
- Conversation Import Adapter

は別々の能力として表示する。
