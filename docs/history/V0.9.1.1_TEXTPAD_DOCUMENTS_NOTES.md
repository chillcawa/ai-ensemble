# AI Ensemble v0.9.1.1 — TextPad Documents

## 目的
簡易テキストエディタを「一時メモ1枚」から、軽量な複数文書エディタへ拡張する。

## 実装
- 文書の新規作成
- 文書切替
- 名前変更
- 削除確認
- 本文のSQLite自動保存
- 保存状態表示（保存中 / 保存済み / 保存エラー）
- 質問欄へ送る
- Context Libraryへ保存
- Paste Historyは従来どおり維持
- 最後の1文書を削除した場合は空の「無題」を自動作成

## SQLite
`text_documents` テーブルを追加:
- id
- title
- content
- created_at
- updated_at

## 旧TextPadからの移行
旧 `ai-ensemble-textpad` に本文がある場合、初回だけSQLite文書「無題」へ移行。
以後の文書本文はlocalStorageではなくSQLiteを正とする。
Paste Historyと現在選択文書IDのみ軽量UI状態としてlocalStorageを継続使用。

## Context Library連携
「Context Libraryに保存」は Project scope / persistent / reference / user_authored として保存する。
重要: Libraryへ保存しただけでは現在のContext Setへ自動追加しない。
「保存」と「AIへ参照させる」を分離し、既存Context原則を維持する。

## 自動保存の安全性
450ms debounce。
文書切替・閉じる・質問欄へ送る・新規作成の前には未保存本文を明示的にflushして、
切替直前の入力が失われないようにしている。

## 検証
- TS/TSX全ソースをTypeScript transpileModuleで構文検査: 0 errors
- この実行環境のnode_modules型定義欠損により `tsc --noEmit` 完走不可
- Rust toolchainなしのため cargo checkはWindows実機で要確認
