# v0.9.3 hotfix1 — ES lib compatibility

Windows `npm run typecheck` で:

`Property 'at' does not exist on type 'TurnBlock[]'`

が発生。

原因:
現在のTypeScript target/libでは `Array.prototype.at()` が利用可能として定義されていない。

修正:
`turns.at(-1)` を `turns[turns.length - 1]` ベースの互換実装へ変更。

tsconfigのtarget/libを上げるより、今回の1箇所だけ互換記法へ戻す方が影響範囲が小さいため、この方法を採用。
