# v0.10.0 hotfix3 — Gemini Dynamic Model Discovery

実機でGeminiの5鏡通信は成功した一方、
Settings > モデル一覧を更新すると取得モデルが全て
「このAdapterでは未対応」になる問題を修正。

## Cause
Gemini model discoveryの `availableNow` 判定が
特定モデルIDのexact allow-listだったため、
Google側の現在のalias / revision / model namingとずれると
通信可能なモデルまで未対応扱いになっていた。

## Fix
Google OpenAI-compatible `/models` が返すモデルについて:

- `gemini-*` conversational family → Chat Completions対応
- 以下を専用Adapter対象として除外:
  - embedding
  - image / imagen
  - live
  - tts
  - robotics
  - computer-use
  - deep-research
  - aqa

モデル名の固定列挙ではなく、Provider family + endpoint semanticsで判定する。

## Principle
Model Discovery ≠ Static Allow-list

Providerが公式に返したモデルIDを尊重しつつ、
AI Ensembleが実装しているAPI surfaceとの互換性だけを機械判定する。
