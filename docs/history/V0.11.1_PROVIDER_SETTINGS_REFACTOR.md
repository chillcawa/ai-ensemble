# v0.11.1 — Provider settings refactor, phase 1

`App.tsx`からProvider／APIキー／モデル管理を独立hookへ分離。

## Extracted

- 初期Provider slot復元
- curated model catalog初期化
- Credential Storeの保存状態確認
- APIキー保存／削除
- Model Discovery
- stale model fallback
- slot表示名／選択モデルのlocalStorage保存

新しい境界: `src/hooks/useProviderSettings.ts`

## Invariants

- 6鏡のProvider ID／slot ID／初期modelを変更しない。
- APIキー本体をJavaScriptへ読み出さない。
- Credential Store、SQLite、Context、Conversation、Handoffの仕様を変更しない。
- Gemini new-user fallback、Qwen Singapore International、Windows GUI subsystem修正を維持。
