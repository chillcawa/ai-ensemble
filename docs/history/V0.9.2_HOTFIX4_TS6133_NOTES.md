# v0.9.2 hotfix4 — TS6133 fix

Windows `npm run typecheck` で発生した:

`src/App.tsx:584:13 - error TS6133: 'marker' is declared but its value is never read.`

を修正。

Context Reload処理では、boundary保存後にSQLiteからConversation Messagesを再読込する設計へ変更済みだったため、
最初の `appendConversationMessage()` の戻り値を保持する必要がなくなっていた。

修正:
- `const marker = await appendConversationMessage(...)`
- → `await appendConversationMessage(...)`

なお `handleDisableAiReferenceAndReset()` 内の別の `marker` は
`setConversationMessages((prev) => [...prev, marker])` で実際に使用しているため変更していない。
