# AI Ensemble v1.3.3 — Pointer reorder hotfix

The v1.3.2 HTML drag source could be grabbed in the Windows Tauri WebView, but valid card drop targets were not accepted and the system displayed a no-drop cursor.

v1.3.3 replaces the browser's native drag-and-drop path with Pointer Events and pointer capture. Hit testing uses the card under the live pointer position, so reordering no longer depends on WebView drag/drop integration. The provider strip auto-scrolls near its horizontal edges. Mouse, pen, and touch use the same implementation; the existing left/right controls remain available.
