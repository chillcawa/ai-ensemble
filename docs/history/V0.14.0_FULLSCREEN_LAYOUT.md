# AI Ensemble v0.14.0 — Fullscreen layout

- Added a native fullscreen toggle to the main header.
- The button changes to `通常表示` while fullscreen is active.
- Fullscreen mode removes the normal 1200 px content cap so provider cards,
  response columns, the composer, and history can use the wider viewport.
- Window resize events keep the UI state synchronized with the native window.
- Added only the Tauri window permissions required to read and change the
  fullscreen state.
